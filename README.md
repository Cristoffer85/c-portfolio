# Cristoffers Portfolio

This project serves as a webapplication storing all Cristoffers projects and contact info and etcetera in one place.

### Main features:
- About Cristoffer
- Services
- Portfolio
- Contact, and 
- Connect

### Created with latest versions of React and Vite 2024-11, and:
- Alot of plain easy to read and understand CSS.  
- One page with smoother scroll and fully responsive. 
- Design and consciously made Color choices
- Simple to use and recreate React Jsx code.
- Pure portfolio/frontend, so no backend nor databases connected here.
